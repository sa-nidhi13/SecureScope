# SecureScope – Target Scope Documentation

# 1. Assessment Overview

Project Name: SecureScope  
Assessment Type: Web Application Vulnerability Assessment and Penetration Testing (VAPT)  
Target Application: OWASP Juice Shop

# 2. Target Information

| Parameter   | Details               |
|-------------|-----------------------|
| Application | OWASP Juice Shop      |
| Target URL  | http://localhost:3000 |
| Target Host | 127.0.0.1             |
| Port        | 3000                  |
| Protocol    | HTTP                  |
| Environment | Local Windows Machine |

# 3. Assessment Scope

The assessment is limited to the locally hosted OWASP Juice Shop application.

The following activities are included:

- Web application reconnaissance
- HTTP request and response analysis
- Port and service identification
- Web application vulnerability testing
- Identification and documentation of security findings

# 4. Testing Tools

- Nmap
- Burp Suite Community Edition
- OWASP ZAP
- Web Browser

# 5. Testing Restrictions

- Testing is restricted to the authorized local lab environment.
- No external systems or applications are included.
- All findings will be documented with evidence and remediation recommendations.

# 6. Assessment Status

Status: In Progress
