# Exercise 4: Automated Web Application Security Scan Using OWASP ZAP

# Objective
To perform an automated baseline security assessment of OWASP Juice Shop using OWASP ZAP.

# Tools Used
- OWASP ZAP
- OWASP Juice Shop

# Target
http://localhost:3000

## Steps Performed
1. Started OWASP ZAP.
2. Configured the target URL.
3. Initiated a baseline security scan.
4. Reviewed the generated alerts.
5. Examined the risk levels and recommendations.
6. Exported the scan results as an HTML report.

# Results
- Scan status: Completed
- High alerts: 0
- Medium alerts: 2
- Low alerts: 0
- Informational alerts: 4

# Conclusion
An automated baseline security assessment was performed on OWASP Juice Shop using OWASP ZAP. The results were reviewed to identify potential security weaknesses and recommendations for further investigation.
